# Оптимизация ре-рендеров

## ✅ Что сделано

### App.tsx
- ✅ Обёрнуты все обработчики в `useCallback`:
  - `markMessageAsDeleted`
  - `markUserMessagesAsDeleted`
  - `handleSendMessage`
  - `handleUserModeration`
  - `handleDeleteMessageFromLog`
  - `handleOpenUserLog`
- ✅ `TabButton` обёрнут в `React.memo`

## 🎯 Результат

**Что улучшилось:**
- Обработчики больше не пересоздаются при каждом рендере
- Дочерние компоненты не ре-рендерятся без необходимости
- Снижена нагрузка на CPU при обновлении состояния

## 📊 Дальнейшая оптимизация

### 1. ChatArea.tsx (приоритет: высокий)

Этот компонент самый тяжёлый - рендерит сообщения чата.

**Что нужно сделать:**
```typescript
// Обернуть рендер сообщения в React.memo
const ChatMessage = React.memo(({ message, onContextMenu }: Props) => {
  // ... рендер сообщения
});

// В itemContent Virtuoso использовать ChatMessage
itemContent={(index, m) => (
  <ChatMessage 
    message={m} 
    onContextMenu={handleMessageContextMenu}
  />
)}
```

**Эффект:** Сообщения не будут ре-рендериться если их данные не изменились.

### 2. Sidebar компоненты

**Обернуть в React.memo:**
- Элементы списка каналов
- Элементы списка зрителей

### 3. Модальные окна

**Уже хорошо оптимизированы:**
- `UserMessageLog`
- `UserProfileModal`
- `AutoModQueue`

Но можно добавить `React.memo` если заметны лаги.

### 4. useMemo для тяжёлых вычислений

**Где применить:**
```typescript
// Фильтрация/сортировка больших списков
const sortedEmotes = useMemo(() => {
  return [...emotes].sort((a, b) => {
    const ua = emoteUsage[a.name] || 0;
    const ub = emoteUsage[b.name] || 0;
    return ub - ua;
  });
}, [emotes, emoteUsage]);
```

## 📈 Ожидаемые улучшения
