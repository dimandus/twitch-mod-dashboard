# Быстрый старт: Кастомная автомодерация

## Что это?

Кастомная автомодерация автоматически подсвечивает сообщения в чате желтым фоном, если они содержат определенные слова или соответствуют регулярным выражениям.

## Как включить?

1. Откройте **Настройки** (кнопка ⚙️)
2. Перейдите на вкладку **Автомодерация**
3. Поставьте галочку **"Включить автомодерацию"**

## Как добавить триггеры?

### Добавление слова

1. Выберите тип: **Слово**
2. Введите слово, например: `spoiler`
3. Нажмите **Добавить** или Enter

Теперь все сообщения со словом "spoiler" будут подсвечены желтым.

### Добавление регулярного выражения

1. Выберите тип: **Регулярное выражение**
2. Введите паттерн, например: `https?://` (для ссылок)
3. Нажмите **Добавить** или Enter

## Примеры триггеров

### Фильтр спама
```
Тип: Регулярное выражение
Значение: (buy|sell|cheap|discount|free)
```

### Фильтр ссылок
```
Тип: Регулярное выражение
Значение: https?://
```

### Фильтр конкретного слова
```
Тип: Слово
Значение: spoiler
```

### Фильтр капса (10+ заглавных букв подряд)
```
Тип: Регулярное выражение
Значение: [A-Z]{10,}
```

## Управление триггерами

- **Включить/выключить** — чекбокс слева от триггера
- **Удалить** — кнопка "Удалить" справа

## Как выглядят подсвеченные сообщения?

- **Фон:** желтый
- **Левая граница:** оранжевая (3px)

## Важно знать

- Проверка работает только для включенных триггеров
- Системные сообщения не проверяются
- Регулярные выражения проверяются без учета регистра
- Невалидные регулярные выражения игнорируются
- Настройки сохраняются автоматически

## Приоритет подсветки

Если сообщение подходит под несколько условий, приоритет такой:

1. 🔴 Удаленные сообщения (красный)
2. 🟡 Триггеры автомодерации (желтый)
3. 🔵 Упоминания вас (синий)
4. 🟦 Рейдеры (голубой)
5. ⚪ Обычные сообщения
