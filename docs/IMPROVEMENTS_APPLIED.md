## 🎯 Влияние на производительность

### Без мемоизации:
- 1000 сообщений × 5 триггеров = 5000 проверок при каждом ре-рендере
- При добавлении нового сообщения все 1000 сообщений проверяются заново

### С мемоизацией:
- Проверка выполняется только для новых/измененных сообщений
- Результаты кэшируются
- Ре-рендер происходит только при изменении зависимостей

**Экономия:** ~99% вычислений при обновлении чата

## 🔧 Как использовать новые функции

### Дублирование триггера
1. Найдите триггер в списке
2. Нажмите кнопку ⎘ (дублировать)
3. Триггер скопируется со всеми настройками

### Экспорт триггеров
1. Нажмите "↓ Экспорт" в заголовке списка триггеров
2. Файл `automod-triggers-{timestamp}.json` будет скачан
3. Сохраните файл для резервной копии или обмена

### Импорт триггеров
1. Нажмите "↑ Импорт" в заголовке списка триггеров
2. Выберите JSON файл с триггерами
3. Триггеры будут добавлены к существующим

## 📝 Формат файла экспорта

```json
[
  {
    "id": "trigger-1234567890-0.123",
    "type": "word",
    "value": "test",
    "enabled": true
  },
  {
    "id": "trigger-1234567891-0.456",
    "type": "regex",
    "value": "https?://",
    "enabled": true
  }
]
```
