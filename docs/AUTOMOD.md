# AutoMod Integration

## Описание

AutoMod — это система автоматической модерации Twitch, которая задерживает потенциально нежелательные сообщения перед их публикацией в чате. Модераторы могут одобрить или удалить эти сообщения.

## Как это работает

1. **PubSub подключение**: Приложение подключается к Twitch PubSub WebSocket для получения событий AutoMod в реальном времени
2. **Автоматическая подписка**: При открытии чатов приложение автоматически подписывается на события AutoMod для этих каналов
3. **Очередь сообщений**: Задержанные сообщения появляются в специальной панели "AutoMod Очередь"
4. **Модерация**: Модератор может одобрить (✓) или удалить (✗) каждое сообщение

## Требования

### Необходимые Scopes

В `main.js` уже добавлены необходимые права:
- `moderator:manage:automod` — управление AutoMod сообщениями
- `moderator:read:automod_settings` — чтение настроек AutoMod
- `moderator:manage:automod_settings` — изменение настроек AutoMod

### Права модератора

Вы должны быть модератором канала, чтобы получать события AutoMod для этого канала.

## Использование

### 1. Открытие очереди AutoMod

Нажмите кнопку **🛡️ AutoMod** в верхней панели приложения.

### 2. Просмотр задержанных сообщений

В открывшемся окне вы увидите:
- **Имя пользователя** и **канал**
- **Текст сообщения**
- **Причину** задержки (агрессивный язык, дискриминация, нецензурная лексика и т.д.)
- **Кнопки действий**: "✓ Разрешить" и "✗ Удалить"

### 3. Модерация

- **Разрешить**: Сообщение будет опубликовано в чате
- **Удалить**: Сообщение будет удалено и не появится в чате

После действия сообщение исчезнет из очереди через 2 секунды.

## Архитектура

### Файлы

```
electron/
  modules/
    TwitchPubSub.js          # PubSub клиент для WebSocket подключения
  main.js                    # IPC handlers для AutoMod
  preload.js                 # API для renderer процесса

src/
  components/
    AutoModQueue.tsx         # UI компонент очереди AutoMod
  App.tsx                    # Интеграция и автоподключение
  vite-env.d.ts             # TypeScript типы
```

### Поток данных

```
Twitch PubSub
    ↓
TwitchPubSub.js (WebSocket)
    ↓
main.js (IPC: automod:message)
    ↓
preload.js (window.electronAPI.automod)
    ↓
AutoModQueue.tsx (React компонент)
```

### API

#### Renderer → Main

```typescript
// Подключение к каналам
window.electronAPI.automod.connect(['channel1', 'channel2'])

// Отключение
window.electronAPI.automod.disconnect()

// Одобрить сообщение
window.electronAPI.automod.approve(msgId)

// Удалить сообщение
window.electronAPI.automod.deny(msgId)

// Подписка на события
const unsubscribe = window.electronAPI.automod.onMessage((data) => {
  console.log('AutoMod message:', data)
})
```

#### Main → Renderer

```javascript
// Отправка события в renderer
mainWindow.webContents.send('automod:message', data)
```

## Структура события AutoMod

```javascript
{
  content_classification: {
    msg_id: "abc123...",  // ID для approve/deny
    category: "aggressive"
  },
  channel: "channelname",
  channel_login: "channelname",
  message: {
    sender: {
      user_id: "12345",
      login: "username"
    },
    content: {
      text: "Текст сообщения"
    }
  },
  reason_code: "aggressive"  // aggressive, identity_based, profanity, sexual
}
```

## Причины задержки

- **aggressive** — Агрессивный язык
- **identity_based** — Дискриминация
- **profanity** — Нецензурная лексика
- **sexual** — Сексуальный контент
- **unknown** — Неизвестная причина

## Troubleshooting

### Сообщения не появляются

1. Проверьте, что вы модератор канала
2. Убедитесь, что AutoMod включен на канале (настройки Twitch)
3. Проверьте консоль на наличие ошибок подключения
4. Убедитесь, что токен имеет необходимые scopes

### Ошибка "Недостаточно прав"

Перелогиньтесь в приложении, чтобы получить новые scopes:
1. Настройки → Выйти
2. Настройки → Войти через Twitch

### PubSub отключается

PubSub автоматически переподключается при разрыве соединения. Если проблема сохраняется:
1. Проверьте интернет-соединение
2. Проверьте, что токен не истёк
3. Перезапустите приложение

## Ограничения

- **История**: Приложение показывает только новые сообщения, задержанные после запуска
- **Множественные модераторы**: Если другой модератор обработает сообщение, оно останется в вашей очереди (обновите вручную)
- **Лимиты Twitch**: PubSub имеет лимит на количество одновременных подключений (50 топиков)
