# 🤖 Новая функция: Кастомная автомодерация

## Что это?

Теперь вы можете автоматически подсвечивать сообщения в чате, которые содержат определенные слова или соответствуют регулярным выражениям!

## Зачем это нужно?

- 🎯 Быстро замечать спам, ссылки, спойлеры
- 🔍 Отслеживать упоминания конкретных тем
- ⚡ Реагировать на проблемные сообщения быстрее
- 🛡️ Дополнительный слой контроля над чатом

## Как выглядит?

Сообщения, которые соответствуют вашим триггерам, будут:
- **Желтая рамка** — сразу бросается в глаза
- **Значок предупреждения ⚠️** — в правом углу сообщения

## Как настроить?

### Шаг 1: Откройте настройки
Нажмите кнопку ⚙️ в правом верхнем углу

### Шаг 2: Перейдите на вкладку "Автомодерация"
Новая вкладка появилась рядом с "Авторизация", "Параметры" и "Дизайн"

### Шаг 3: Включите автомодерацию
Поставьте галочку "Включить автомодерацию"

### Шаг 4: Добавьте триггеры
Выберите тип и введите значение:
- **Слово** — для точного совпадения (например, "spoiler")
- **Регулярное выражение** — для гибких паттернов (например, "https?://")

## Примеры триггеров

### 🔗 Фильтр ссылок
```
Тип: Регулярное выражение
Значение: https?://
```
Подсветит все сообщения со ссылками

### 📢 Фильтр спама
```
Тип: Регулярное выражение
Значение: (buy|sell|cheap|discount|free)
```
Подсветит сообщения с типичными спам-словами

### 🎬 Фильтр спойлеров
```
Тип: Слово
Значение: spoiler
```
Подсветит сообщения со словом "spoiler"

### 🔊 Фильтр капса
```
Тип: Регулярное выражение
Значение: [A-Z]{10,}
```
Подсветит сообщения с 10+ заглавными буквами подряд

## Управление триггерами

- ✅ **Включить/выключить** — чекбокс слева
- 🗑️ **Удалить** — кнопка справа
- 📝 **Редактировать** — удалите и создайте заново

## Важные моменты

- ✅ Настройки сохраняются автоматически
- ✅ Работает в реальном времени
- ✅ Не требует перезапуска
- ✅ Не влияет на производительность
- ⚠️ Проверка только на клиенте (не блокирует сообщения на сервере)

## Приоритет подсветки

Если сообщение подходит под несколько условий:
1. 🔴 **Удаленные** — красный (самый высокий приоритет)
2. 🟡 **Триггеры** — желтый
3. 🔵 **Упоминания** — синий
4. 🟦 **Рейдеры** — голубой
5. ⚪ **Обычные** — стандартный фон

## Советы по использованию

### Для начинающих
Начните с простых слов:
- `spoiler`
- `spam`
- `scam`

### Для продвинутых
Используйте регулярные выражения:
- `\d{3}-\d{3}` — номера телефонов
- `@\w+` — упоминания
- `(bad|wrong|hate)` — негативные слова
