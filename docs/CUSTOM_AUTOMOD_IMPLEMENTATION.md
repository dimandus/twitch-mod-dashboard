# Реализация кастомной автомодерации

## ✅ Что добавлено

### 1. Store для автомодерации
**Файл:** `src/stores/autoModerationStore.ts`
- Управление состоянием включения/выключения
- Хранение списка триггеров
- CRUD операции для триггеров
- Автоматическое сохранение через Zustand persist

### 2. Утилита проверки сообщений
**Файл:** `src/utils/autoModHelpers.ts`
- Функция `checkAutoModTriggers()` — проверяет сообщение на соответствие триггерам
- Поддержка двух типов триггеров:
  - **Слово** — точное совпадение с границами слов
  - **Regex** — гибкие паттерны
- Обработка ошибок для невалидных регулярных выражений

### 3. Компонент настроек
**Файл:** `src/components/settings/AutoModTab.tsx`
- UI для включения/выключения автомодерации
- Форма добавления триггеров
- Список триггеров с управлением (включить/выключить/удалить)
- Подсказки для пользователей

### 4. Интеграция в настройки
**Файл:** `src/views/SettingsView.tsx`
- Добавлена новая вкладка "Автомодерация"
- Импорт компонента AutoModTab

### 5. Визуальная подсветка сообщений
**Файл:** `src/components/chat/ChatMessageItem.tsx`
- Проверка сообщений на триггеры
- Желтая рамка (2px, #f59e0b) для сообщений с триггерами
- Значок предупреждения ⚠️ в правом углу
- Приоритет подсветки (удаленные > триггеры > упоминания > рейдеры)

### 6. Обновление типов
**Файл:** `src/types/chat.ts`
- Добавлено поле `autoModTriggered?: boolean` для будущего расширения

### 7. Документация
- `docs/CUSTOM_AUTOMOD.md` — полная документация
- `docs/CUSTOM_AUTOMOD_QUICKSTART.md` — быстрый старт
- Обновлен `README.md` с информацией о новой функции

## 🎯 Как это работает

1. **Пользователь настраивает триггеры** в Настройках → Автомодерация
2. **Триггеры сохраняются** в localStorage через Zustand persist
3. **При рендере сообщения** ChatMessageItem проверяет текст через `checkAutoModTriggers()`
4. **Если триггер сработал** — применяется желтый фон и оранжевая граница
5. **Визуальная индикация** помогает модератору быстро заметить важные сообщения

## 🔧 Технические детали

### Производительность
- Проверка выполняется только для включенных триггеров
- Невалидные regex игнорируются с предупреждением
- Проверка не блокирует рендеринг

### Хранение данных
```typescript
{
  enabled: boolean,
  triggers: [
    {
      id: string,
      type: 'word' | 'regex',
      value: string,
      enabled: boolean
    }
  ]
}
```

### Приоритет подсветки
```
1. isDeleted → красный фон
2. isAutoModTriggered → желтый фон
3. isMentionedSelf → синий фон
4. isRaider → голубой фон
5. default → обычный фон
```
