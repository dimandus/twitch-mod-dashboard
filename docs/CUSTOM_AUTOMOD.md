# Кастомная автомодерация

## Описание

Система кастомной автомодерации позволяет автоматически подсвечивать сообщения в чате, которые содержат определенные слова или соответствуют регулярным выражениям.

## Возможности

- ✅ Включение/выключение автомодерации
- ✅ Добавление триггеров двух типов:
  - **Слово** — точное совпадение слова с учетом границ
  - **Регулярное выражение** — гибкие паттерны для поиска
- ✅ Включение/выключение отдельных триггеров
- ✅ Удаление триггеров
- ✅ Визуальная подсветка сообщений желтым фоном
- ✅ Оранжевая левая граница для быстрой идентификации

## Использование

### Настройка

1. Откройте **Настройки** → вкладка **Автомодерация**
2. Включите автомодерацию чекбоксом
3. Добавьте триггеры:
   - Выберите тип: **Слово** или **Регулярное выражение**
   - Введите значение
   - Нажмите **Добавить** или Enter

### Типы триггеров

#### Слово
Ищет точное совпадение слова с учетом границ слов.

**Примеры:**
- `test` найдет: "test", "Test", "TEST"
- `test` НЕ найдет: "testing", "contest", "attest"

#### Регулярное выражение
Гибкий поиск по паттернам.

**Примеры:**
- `test.*` найдет: "test", "testing", "tester"
- `(bad|wrong)` найдет: "bad", "wrong"
- `\d{3}-\d{3}` найдет: "123-456"

### Управление триггерами

- **Включить/выключить** — чекбокс слева от триггера
- **Удалить** — кнопка "Удалить" справа
- **Просмотр** — все триггеры отображаются списком с типом и значением

## Визуальная индикация

Сообщения, соответствующие триггерам:
- **Рамка:** желтая (2px, #f59e0b)
- **Значок:** ⚠️ в правом углу с подсказкой

Приоритет подсветки:
1. Удаленные сообщения (красный)
2. Триггеры автомодерации (желтый)
3. Упоминания (синий)
4. Рейдеры (голубой)
5. Обычные сообщения

## Технические детали

### Архитектура

- **Store:** `autoModerationStore.ts` — Zustand store с persist
- **Утилиты:** `autoModHelpers.ts` — проверка сообщений
- **Компонент:** `AutoModTab.tsx` — UI настроек
- **Интеграция:** `ChatMessageItem.tsx` — подсветка сообщений

### Производительность

- Проверка выполняется только для включенных триггеров
- Невалидные регулярные выражения игнорируются
- Проверка не блокирует рендеринг чата

### Хранение данных

Настройки сохраняются локально через Zustand persist:
- Состояние включения/выключения
- Список триггеров с типами и значениями
- Состояние каждого триггера (включен/выключен)

## Примеры использования

### Фильтр спама
```
Тип: Регулярное выражение
Значение: (buy|sell|cheap|discount)
```

### Фильтр ссылок
```
Тип: Регулярное выражение
Значение: https?://
```

### Фильтр конкретных слов
```
Тип: Слово
Значение: spoiler
```

### Фильтр капса
```
Тип: Регулярное выражение
Значение: [A-Z]{10,}
```

## Ограничения

- Регулярные выражения проверяются с флагом `i` (case-insensitive)
- Невалидные регулярные выражения игнорируются с предупреждением в консоли
- Системные сообщения не проверяются
- Проверка выполняется только на клиенте (не блокирует сообщения на сервере)
