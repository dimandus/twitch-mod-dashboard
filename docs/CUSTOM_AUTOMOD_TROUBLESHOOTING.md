# Отладка автомодерации

## Проблема: Сообщения не подсвечиваются

### Шаг 1: Проверьте настройки

1. Откройте **Настройки** → **Автомодерация**
2. Убедитесь, что:
   - ✅ Галочка "Включить автомодерацию" стоит
   - ✅ Есть хотя бы один триггер
   - ✅ Триггер включен (галочка слева от триггера)

### Шаг 2: Проверьте консоль браузера

1. Откройте DevTools (F12 или Ctrl+Shift+I)
2. Перейдите на вкладку **Console**
3. Отправьте тестовое сообщение в чат
4. Ищите сообщения:
   - `[ChatMessageItem] Checking message:` — проверка сообщения
   - `[AutoMod] Triggered by word:` — срабатывание триггера

### Шаг 3: Проверьте localStorage

В консоли браузера выполните:

```javascript
// Проверка данных
const data = JSON.parse(localStorage.getItem('twitch-automod-store'));
console.log('Enabled:', data?.state?.enabled);
console.log('Triggers:', data?.state?.triggers);
```

Должно быть:
- `enabled: true`
- `triggers: [...]` — массив с вашими триггерами

### Шаг 4: Тестовый скрипт

Скопируйте содержимое файла `debug-automod.js` в консоль браузера и запустите.

### Шаг 5: Проверьте триггеры

#### Для типа "Слово"
- ✅ Правильно: `test` найдет "test", "Test", "TEST"
- ❌ Неправильно: `test` НЕ найдет "testing", "contest"

#### Для типа "Regex"
- ✅ Правильно: `test.*` найдет "test", "testing", "tester"
- ✅ Правильно: `https?://` найдет "http://", "https://"
- ❌ Неправильно: `[invalid(` — невалидное регулярное выражение

### Шаг 6: Перезапустите приложение

Если ничего не помогло:
1. Закройте приложение
2. Откройте снова
3. Проверьте настройки автомодерации
4. Попробуйте снова

### Шаг 7: Очистите localStorage (крайний случай)

⚠️ **Внимание:** Это удалит ВСЕ настройки автомодерации!

```javascript
localStorage.removeItem('twitch-automod-store');
```

Затем:
1. Перезапустите приложение
2. Настройте автомодерацию заново

## Частые проблемы

### Проблема: "Enabled: false"
**Решение:** Включите автомодерацию в настройках

### Проблема: "Triggers: []"
**Решение:** Добавьте триггеры в настройках

### Проблема: Триггер есть, но `enabled: false`
**Решение:** Включите триггер (галочка слева)

### Проблема: Регулярное выражение не работает
**Решение:** Проверьте синтаксис регулярного выражения:
- Используйте онлайн-тестер: https://regex101.com/
- Убедитесь, что выражение валидное

### Проблема: Слово не находится
**Решение:** 
- Проверьте, что слово написано правильно
- Помните: тип "Слово" ищет ТОЧНОЕ совпадение с границами слов
- Если нужно найти часть слова, используйте тип "Regex"

## Примеры правильных триггеров

### Слова
```
test
spoiler
spam
scam
```

### Регулярные выражения
```
https?://              # Ссылки
(buy|sell|cheap)       # Спам-слова
[A-Z]{10,}             # Капс (10+ заглавных букв)
\d{3}-\d{3}            # Номера телефонов
```

## Если ничего не помогло

Создайте issue в репозитории с:
1. Скриншотом настроек автомодерации
2. Примером сообщения, которое должно подсветиться
3. Выводом из консоли браузера
4. Результатом проверки localStorage
