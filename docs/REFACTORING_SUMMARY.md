## 📁 Созданная структура

```
src/
├── constants/
│   ├── chatConstants.ts          # Константы для чата
│   └── sidebarConstants.ts       # Константы для sidebar
│
├── utils/
│   ├── chatHelpers.ts            # Утилиты для чата
│   └── viewersHelpers.ts         # Утилиты для зрителей
│
├── hooks/
│   ├── useSendMessage.ts         # Отправка сообщений ⭐
│   ├── useModeration.ts          # Модерация ⭐
│   ├── useUserLog.ts             # Лог пользователя ⭐
│   ├── useLoginSync.ts           # Синхронизация логина ⭐
│   ├── useChannelSync.ts         # Синхронизация каналов ⭐
│   ├── useUserInfoFetch.ts       # Загрузка инфо ⭐
│   ├── useAutoModConnection.ts   # AutoMod ⭐
│   ├── useChatPanes.ts           # Панели чата ⭐
│   ├── useChatModes.ts           # Режимы чата ⭐
│   └── useUIScale.ts             # Масштабирование ⭐
│
└── components/
    ├── chat/                     # Компоненты чата
    │   ├── Badges.tsx            # Рендеринг бейджей ⭐
    │   ├── MessageWithEmotes.tsx # Сообщение с эмотами
    │   ├── ChatMessageItem.tsx   # Отдельное сообщение
    │   ├── ChatModesBar.tsx      # Панель режимов
    │   ├── EmotePicker.tsx       # Пикер эмотов
    │   ├── Autocomplete.tsx      # Автокомплит @ и /
    │   └── ChatContextMenu.tsx   # Контекстное меню
    │
    ├── sidebar/                  # Компоненты sidebar
    │   ├── ChannelList.tsx       # Список каналов
    │   ├── ViewersList.tsx       # Список зрителей (использует Badges ⭐)
    │   └── AddChannelModal.tsx   # Модалка добавления
    │
    └── settings/                 # Компоненты настроек
        ├── AuthTab.tsx           # Вкладка авторизации
        ├── ParamsTab.tsx         # Вкладка параметров
        └── DesignTab.tsx         # Вкладка дизайна
```

⭐ = Переиспользуемый компонент/хук

## 🎯 Преимущества рефакторинга

### 1. Читаемость
- ✅ Файлы в 2-3 раза меньше
- ✅ Понятная структура
- ✅ Один компонент = одна задача

### 2. Поддержка
- ✅ Легко найти нужный код
- ✅ Изменения в одном месте
- ✅ Меньше конфликтов при merge

### 3. Переиспользование
- ✅ Badges используется в 2 местах
- ✅ chatHelpers используются везде
- ✅ Хуки изолированы и переиспользуемы

### 4. Тестируемость
- ✅ Компоненты можно тестировать отдельно

- ✅ Легко добавить новый компонент
