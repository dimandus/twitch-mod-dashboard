# Twitch Mod Dashboard

Настольное приложение на Electron + React для модераторов Twitch-каналов.  
Позволяет одновременно следить за несколькими чатами, быстро применять модерацию, смотреть логи сообщений и профили пользователей.

---

## ✨ Возможности

### 💬 Чат
- Подключение к нескольким Twitch-чатам одновременно (через IRC / tmi.js)
- Отображение сообщений с эмодзи и бейджами
- Пометка удалённых сообщений
- Отображение очистки чата
- Локальная история в рамках сессии
- Упоминания текущего пользователя
- Поддержка первых сообщений и участников рейдов

### 🛡️ AutoMod
- Просмотр сообщений, задержанных AutoMod
- Одобрение или удаление сообщений в реальном времени
- Автоматическое подключение к каналам через PubSub
- Подробная документация: [AUTOMOD.md](./AUTOMOD.md)

### 🔨 Модерация
- Бан / разбан / таймауты (через Helix API)
- Удаление отдельных сообщений
- Полная очистка чата
- Управление режимами чата:
  - Медленный режим (slow mode)
  - Режим только для подписчиков
  - Режим только для фолловеров
  - Режим только эмодзи
  - Уникальные сообщения (R9K)
  - Shield Mode
- Отправка объявлений с цветами

### 📊 Информация о пользователях
- **Лог сообщений**: просмотр всех сообщений пользователя по каналам
- **Профиль**: аватар, баннер, описание, дата создания, просмотры
- **Модерация из лога**: бан/таймаут/удаление прямо из истории сообщений

### 📋 Управление каналами
- Собственный список каналов
- Импорт каналов, где вы модератор
- Импорт каналов, на которые вы подписаны
- Фильтр "Все" / "Где я модератор"
- Статус стрима (онлайн/офлайн, зрители, количество модераторов)

### 👥 Список зрителей
- Список текущих зрителей для выбранного канала
- Подсветка модераторов и стримера
- Контекстное меню для модерации и просмотра логов/профиля
- Автоматическое обновление

## 🔑 Настройка Twitch OAuth

### Вариант 1: Прямой OAuth (рекомендуется)

1. Перейдите на [Twitch Developer Console](https://dev.twitch.tv/console/apps)
2. Создайте новое приложение:
   - **Name:** любое название
   - **OAuth Redirect URL:** `http://localhost:58585/auth/twitch/callback`
   - **Category:** Website Integration или Application Integration
3. Сохраните **Client ID** и сгенерируйте **Client Secret**
4. Запустите приложение
5. Перейдите в **Настройки** → вкладка **Авторизация**
6. Введите Client ID и Client Secret, нажмите "Сохранить"
7. Нажмите **"Войти (прямой OAuth)"**

### Вариант 2: Через Dimandus

Если у вас есть доступ к серверу Dimandus:

1. В настройках нажмите **"Войти через Dimandus"**
2. Авторизуйтесь на странице Dimandus
3. Токены будут автоматически сохранены

### Необходимые права (Scopes)

Приложение запросит следующие права:

```
chat:read                           # Чтение чата
chat:edit                           # Отправка сообщений
moderation:read                     # Чтение модерации
moderator:manage:banned_users       # Управление банами
moderator:manage:chat_messages      # Удаление сообщений
moderator:manage:chat_settings      # Настройки чата
moderator:manage:announcements      # Объявления
moderator:manage:shield_mode        # Shield Mode
moderator:read:shield_mode          # Чтение Shield Mode
moderator:read:chatters             # Список зрителей
user:read:moderated_channels        # Модерируемые каналы
user:read:follows                   # Подписки
user:write:chat                     # Отправка через Helix
user:read:emotes                    # Эмодзи пользователя
moderator:manage:automod            # Управление AutoMod
moderator:read:automod_settings     # Настройки AutoMod
moderator:manage:automod_settings   # Изменение настроек AutoMod
```

## 🎮 Использование

### Первый запуск

1. Запустите приложение
2. Перейдите в **Настройки** и авторизуйтесь
3. Вернитесь на **Dashboard**
4. Добавьте каналы:
   - Вручную через кнопку **+**
   - Импортируйте модерируемые каналы (кнопка **M**)
   - Импортируйте подписки (кнопка **♥**)

### Работа с чатами

- **Открыть чат**: клик по каналу в списке или ПКМ → "Открыть чат"
- **ПКМ по сообщению**: профиль, лог, модерация, таймаут, бан
- **ПКМ по зрителю**: те же действия
- **Отправка сообщений**: поле ввода внизу чата
- **Команды**: `/ban`, `/timeout`, `/clear` и другие

### AutoMod

1. Нажмите кнопку **🛡️ AutoMod** в верхней панели
2. Просматривайте задержанные сообщения
3. Одобряйте (✓) или удаляйте (✗) сообщения

### Модерация

- **Быстрые действия**: ПКМ по сообщению или пользователю
- **Режимы чата**: кнопки в верхней части чата
- **Shield Mode**: кнопка 🛡️ в панели чата
- **Объявления**: команда `/announce текст`

## ⚠️ Известные ограничения

- **История чата**: Twitch не предоставляет историю через API. Сообщения видны только с момента запуска приложения
- **Права модератора**: Большинство функций требуют прав модератора на канале
- **AutoMod**: Работает только для каналов, где вы модератор и AutoMod включен
- **Список зрителей**: Может быть неполным для очень больших каналов

## 🐛 Troubleshooting

### "Login authentication failed"
- Токен истёк
- Приложение попытается автоматически обновить токен
- Если не помогло — перелогиньтесь через Настройки

### "Недостаточно прав доступа"
- Не хватает scopes
- Выйдите и войдите заново для получения новых прав

### AutoMod не работает
- Убедитесь, что вы модератор канала
- Проверьте, что AutoMod включен в настройках канала на Twitch
- Проверьте наличие необходимых scopes в Настройках

### Сообщения не отправляются
- Проверьте подключение к интернету
- Убедитесь, что вы залогинены
- Проверьте, что у вас есть права на отправку сообщений
